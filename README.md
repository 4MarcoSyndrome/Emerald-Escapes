# Emerald-Escapes

First Assessment for Web Design course for Higher Diploma in Computing

logo generated with [Canva](https://www.canva.com/) in .jpg and converted in .svg with [Convertio](https://convertio.co/)

Deployed on [Git Pages](https://4marcosyndrome.github.io/Emerald-Escapes/)

## Navbar

I used a code from codepen [Modern Glassmorphic Navigation Bar with Theme Toggle](https://codepen.io/themrsami/pen/YPzvmyY) adjusted with my requirements.

## Colors

Based on [Irish Flag](https://www.flagcolorcodes.com/ireland) official colors.
